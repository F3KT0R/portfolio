## Why rebuild
The previous version was a single-page section layout. It looked good, but it didn’t scale well for deep project narratives.

## Goals
- Turn projects into case studies.
- Improve SEO and share previews.
- Make the UI feel like a product.

## Implementation
- App Router structure (`app/`) and new information architecture.
- MDX content in `content/projects`.
- GitHub repo stats fetched server-side and cached.

## Next
- Add a lightweight CI pipeline.
- Expand case studies with more screenshots, metrics, and decisions.
